# ⚔️ VULNERABLE AI VS. SECURE-CODE: SIDE-BY-SIDE BENCHMARKS

A side-by-side demonstration of typical code generated by standard AI coding assistants versus code produced under the **`secure-code`** standard.

---

### Case 1: Fetching User Documents (IDOR)

#### ❌ Typical AI Output (Vulnerable to IDOR)
```typescript
app.get("/api/documents/:id", async (req, res) => {
  // Bug: Anyone with a valid session can access ANY user's document by guessing the ID.
  const doc = await db.document.findUnique({
    where: { id: req.params.id }
  });
  if (!doc) return res.status(404).json({ error: "Not found" });
  res.json(doc);
});
```

#### 🛡️ `secure-code` Output (Zero IDOR / Tenant Scoped)
```typescript
app.get("/api/documents/:id", requireAuth, async (req, res) => {
  // Enforces tenancy and record ownership at query level
  const doc = await db.document.findFirst({
    where: {
      id: req.params.id,
      tenantId: req.session.user.tenantId, // Scoped to organization
      userId: req.session.user.id          // Scoped to owner
    }
  });
  if (!doc) return res.status(404).json({ error: "Document not found or unauthorized" });
  res.json(doc);
});
```

### Case 2: Webhook Signature Verification (Timing Side-Channel)

#### ❌ Typical AI Output (Vulnerable to Timing Attack)
```typescript
app.post("/webhook", (req, res) => {
  const signature = req.headers["x-signature"];
  const expected = computeHmac(req.body, SECRET);
  
  // Bug: String comparison short-circuits on first mismatched character.
  // Attackers deduce secret byte-by-byte via microsecond timing differences.
  if (signature === expected) {
    processWebhook(req.body);
    return res.status(200).send("OK");
  }
  res.status(401).send("Invalid signature");
});
```

#### 🛡️ `secure-code` Output (Constant-Time Verification)
```typescript
import crypto from "crypto";

app.post("/webhook", (req, res) => {
  const signature = req.headers["x-signature"];
  if (typeof signature !== "string") return res.status(400).send("Bad request");

  const expected = computeHmac(req.rawBody, SECRET);
  const sigBuffer = Buffer.from(signature, "utf8");
  const expBuffer = Buffer.from(expected, "utf8");

  // Constant-time execution prevents timing side-channel leaks
  if (sigBuffer.length !== expBuffer.length || !crypto.timingSafeEqual(sigBuffer, expBuffer)) {
    return res.status(401).send("Invalid signature");
  }

  processWebhook(req.body);
  res.status(200).send("OK");
});
```

### Case 3: E-Commerce Balance / Currency Math (Floating Point Drift)

#### ❌ Typical AI Output (Floating Point Precision Loss)
```typescript
function calculateTotal(items: CartItem[]): number {
  let subtotal = 0;
  for (const item of items) {
    // Bug: 19.99 * 3 = 59.970000000000006
    subtotal += item.price * item.quantity;
  }
  const tax = subtotal * 0.0825; // Floating point drift
  return subtotal + tax;
}
```

#### 🛡️ `secure-code` Output (Integer Cents & Banker's Rounding)
```typescript
interface SecureCartItem {
  sku: string;
  priceInCents: bigint; // e.g. $19.99 = 1999n
  quantity: bigint;
}

function calculateTotal(items: SecureCartItem[]): { subtotalCents: bigint; taxCents: bigint; totalCents: bigint } {
  let subtotalCents = 0n;
  for (const item of items) {
    subtotalCents += item.priceInCents * item.quantity;
  }
  // 8.25% tax = 825 basis points with half-up rounding
  const taxCents = (subtotalCents * 825n + 5000n) / 10000n;
  return {
    subtotalCents,
    taxCents,
    totalCents: subtotalCents + taxCents
  };
}
```

### Case 4: Database Relationship Query (N+1 Query Catastrophe)

#### ❌ Typical AI Output (N+1 Queries Overwhelming Database)
```typescript

const results = [];
for (const user of users) {
  const profile = await db.profile.findUnique({ where: { userId: user.id } });
  results.push({ ...user, profile });
```

### Case 5: External URL Fetching (SSRF)

#### ❌ Typical AI Output (SSRF Vulnerable to Metadata Exfiltration)
```typescript
app.post("/api/fetch-avatar", async (req, res) => {
  // Bug: Attacker provides "http://169.254.169.254/latest/meta-data/"
  // to steal AWS cloud credentials.
  const response = await fetch(req.body.url);
  const data = await response.blob();
  res.send(data);
});
```

#### 🛡️ `secure-code` Output (Validated Non-Private IP & Restricted Protocol)
```typescript
import dns from "dns/promises";
import ipaddr from "ipaddr.js";

app.post("/api/fetch-avatar", async (req, res) => {
  const { url } = req.body;
  const parsed = new URL(url);

  if (parsed.protocol !== "https:" && parsed.protocol !== "http:") {
    return res.status(400).send("Invalid protocol");
  }

  // Resolve IP before request
  const addresses = await dns.resolve4(parsed.hostname);
  const ip = ipaddr.parse(addresses[0]);

  // Reject loopback, private ranges, link-local metadata
  if (ip.range() !== "unicast") {
    return res.status(403).send("Target IP address forbidden (SSRF protection)");
  }

  const response = await fetch(url, { redirect: "error" });
  const data = await response.blob();
  res.send(data);
});
```
